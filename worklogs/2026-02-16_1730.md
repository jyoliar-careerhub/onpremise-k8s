### 발견된 이슈 및 해결

#### 1. Raspberry Pi cgroup memory 미활성화
- **증상**: kubelet 시작 실패 - `missing required cgroups: memory`
- **원인**: Debian 13 Trixie에서 cgroup memory가 기본 비활성
- **해결**: `raspi-cgroup-memory.yaml` 플레이북 생성 → `/boot/firmware/cmdline.txt`에 `cgroup_memory=1 cgroup_enable=memory` 추가 후 reboot

#### 2. Raspberry Pi zram swap 활성화
- **증상**: kubelet 시작 실패 - swap 감지
- **원인**: Debian 13에서 zram swap 기본 활성
- **해결**: `raspi-disable-swap.yaml` 플레이북 생성 → systemd 서비스 마스킹으로 영구 비활성화

#### 3. imagePullPolicy 대소문자
- **증상**: kubelet이 kube-vip static pod 거부
- **원인**: 인벤토리의 `image_pull_type=always`가 소문자로 전달됨 (K8s는 `Always` 요구)
- **해결**: 템플릿에 `| capitalize` Jinja2 필터 추가

#### 4. kube-vip RBAC 오류 (K8s 1.29+)
- **증상**: kube-vip CrashLoopBackOff - serviceaccount token / lease 접근 실패
- **원인**: K8s 1.29+에서 `admin.conf`의 권한이 제한됨
- **해결**: 첫 번째 마스터는 `super-admin.conf`, 나머지는 `admin.conf` 마운트하도록 템플릿 수정

#### 5. kube-vip `kubernetes:6443` DNS 실패 (핵심 이슈)
- **증상**: `lookup kubernetes on DNS: no such host` → VIP 미할당 → 클러스터 접속 불가
- **원인**: kube-vip 소스 코드 분석 결과, `cp_enable=true`이고 `kubernetes_addr` 미설정 시 kubeconfig의 server URL을 무시하고 `kubernetes:6443`으로 강제 오버라이드. `hostNetwork: true`이므로 호스트 DNS 사용 → `kubernetes` 해석 불가
- **해결**: `kubernetes_addr: "{{ ansible_host }}:6443"` 환경변수 추가
- **참고**: `vip_kubernetes`는 존재하지 않는 환경변수 (잘못된 정보였음)

#### 6. Ansible 조건문 boolean 타입 오류
- **증상**: `Conditional result (True) was derived from value of type 'str'`
- **원인**: 인벤토리의 `kube_vip_lb_enabled=true`가 문자열로 해석됨
- **해결**: `when:` 조건에 `| bool` 필터 추가

#### 7. cleanup 후 CRI-O 비활성
- **증상**: `kubeadm config images pull` 실패 - containerd 소켓 찾음
- **원인**: `cleanup-all-vms.yaml`이 CRI-O 중지시킴, 마스터만 재시작하고 워커 노드 누락
- **해결**: 전체 노드에서 CRI-O 수동 재시작

#### 8. cleanup 후 apt 깨짐
- **증상**: `Failed to update apt cache` - GPG 키 누락
- **원인**: cleanup이 GPG 키는 삭제하지만 apt source 파일(`cri-o.list`, `kubernetes.list`)은 남김
- **해결**: 깨진 source 파일 수동 제거 후 `repos.yaml` 재실행

#### 9. Debian 13에서 `software-properties-common` 없음
- **증상**: repos.yaml 실패
- **원인**: Debian 13 Trixie에서 해당 패키지 미제공
- **해결**: repos role에서 제거 (의존성 없음 확인)
